# Security

This repository is a static portfolio site: it has no sign-in, no database and no forms, and it keeps nothing about visitors on a server.

To report a vulnerability, use **Report a vulnerability** on this repository's [Security tab](https://github.com/KathFK1234/KathFK1234/security), which keeps it private. Please do not open a public issue. I aim to reply within a week.

The projects described on this site are separate systems. Report anything about one of them to its own repository.
