# Chema Backend — agricultural data and decision support

A data-driven backend that connects agricultural knowledge, AI assistance, and actionable information, built during my time as a Backend Developer Intern at Chakula Africa (Feb 2026 — Apr 2026).

It is deliberately practical: useful output matters more than impressive automation.

  stack: FastAPI · PostgreSQL · SQLAlchemy · Supabase · Groq

  api/           endpoints and access control
  analytics/     forecasting and reporting
  integration/   LLM assistance and deployment

The source is not public, so these folders hold notes, not code.
