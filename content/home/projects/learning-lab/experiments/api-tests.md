# api-tests — small checks for reliable backend behavior

A habit more than a project: before trusting an endpoint, write the smallest test that would fail if it lied.

MoodForecast AI started with 31 of these: 23 on the scoring engine and 8 on the endpoints. It now has 590, and 66 more that drive the page in a real browser. See `~/projects/moodforecast-ai`.
