# terminal-ui — this portfolio and its shell behavior

You are inside this experiment right now.

- The file system you are browsing is a real folder in the repository (`content/home`). Adding a file there adds it to the terminal.
- Commands are plain functions in a registry; `help` and `man` are generated from it, so they cannot drift out of date.
- Tab completes commands and paths. Arrow keys walk the history.
